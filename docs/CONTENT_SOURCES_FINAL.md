# MADAR Content Sources

## Quran
Arabic Uthmani text is redistributed verbatim from Tanzil Project Version 1.1. Tanzil permits verbatim use in applications when the source is clearly identified and a link to tanzil.net is retained. The text must not be modified.

The reproducible build source is the public Mushaf-Learning/quran-text mirror, whose repository identifies Tanzil as the upstream source. The build records the upstream URL and SHA-256 of the downloaded text.

## Hadith and other material
MADAR does not hand-author religious text. Collections are consumed only from datasets with an explicit redistribution licence, and the exact source, licence and revision are recorded in the generated manifest. Sources with no licence are rejected.

## Release gate
A content package must have provenance, licence, SHA-256, expected counts, structural validation and attribution. Scholarly uncertainty is never converted into an app-generated certainty.
