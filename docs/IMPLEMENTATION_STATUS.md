# حالة تنفيذ مَدار

## ما تم إغلاقه في الدفعة النهائية
- Flutter + Riverpod + GoRouter + Drift مع طبقات واضحة.
- Riverpod صار مهيأ من نقطة الدخول الفعلية.
- قاعدة البيانات المحلية للمحتوى والمستخدم والتتبع.
- حفظ المفضلة والملاحظات والتقدم والإعدادات.
- حزمة قرآن Uthmani يتم توليدها أثناء البناء من مصدر Tanzil موثوق، مع تحقق 114 سورة و6236 آية وتسجيل SHA-256 ومصدر الترخيص.
- أسماء الله الحسنى 99 اسماً من حزمة مرخصة ومثبتة الإصدار.
- أذكار حقيقية من حزمة مرخصة ومثبتة الإصدار، مع المصدر وعدد التكرار.
- تنزيل مجموعات الحديث عند الطلب من مستودع MIT مثبت على commit محدد، مع إدخال النص والمرجع وبيانات الدرجة الموجودة في المصدر.
- بحث محلي بعد تنزيل المحتوى.
- مواقيت الصلاة مرتبطة بالموقع الذي يوافق عليه المستخدم أو بالإحداثيات اليدوية، بدون موقع افتراضي مخفي.
- القبلة مرتبطة بالموقع والحساسات مع بوصلة حية.
- التسبيح يحفظ الجلسة والهدف محلياً.
- الإشعارات المحلية مهيأة.
- تشغيل الصوت في الخلفية مهيأ عبر just_audio_background، مع إعدادات Android/iOS في مسار البناء.
- الشعار والأيقونة المتجهة موجودان في assets/branding، وفق مفهوم صفحتين مفتوحتين ومدار واحد متداخل.
- GitHub Actions للبناء يدوي فقط عبر workflow_dispatch.
- إعداد Android وiOS يتم إنشاؤه في بيئة البناء عند غيابه، ثم يمر عبر build_runner وanalyze وtest قبل البناء.

## بوابة الإنتاج التي لم يتم الادعاء بتجاوزها
لا يمكن وصف APK أو IPA بأنه مختبر إنتاجياً قبل تشغيل workflow فعلي على GitHub وعلى أجهزة حقيقية. بيئة المحادثة الحالية لا تحتوي Flutter SDK ولا جهاز Android/iOS فعلي، لذلك لم يتم اختلاق نتيجة نجاح.

الاختبارات المطلوبة في أول تشغيل للبناء:
1. dart run tool/prepare_content.dart
2. dart run build_runner build --delete-conflicting-outputs
3. flutter analyze
4. flutter test
5. Android APK على جهاز فعلي، خصوصاً Android 10.
6. iOS build على macOS runner.
7. اختبار الإشعارات بعد إعادة التشغيل وتوفير الطاقة.
8. اختبار الصوت من شاشة القفل وBluetooth.
9. اختبار القبلة في وضع حساس ضعيف/بدون حساس.
10. اختبار الهجرة من schema 2.

## المحتوى
لا يوجد نص ديني مؤلف بواسطة النموذج داخل الحزم. المحتوى الذي يدخل التطبيق يأتي من مصادر خارجية موثقة، ويحتفظ التطبيق بالمصدر والترخيص والإصدار. مصادر بلا ترخيص لا تدخل الحزمة.

## ملاحظة مهمة
الترجمة والتفسير والكتب الكبيرة لا يتم اختلاقها لإظهار الشاشة مكتملة. عندما لا توجد رخصة إعادة توزيع واضحة، تبقى المادة كمصدر/إضافة قابلة للتنزيل أو تظل خارج الحزمة بدلاً من ادعاء ملكيتها.

## البناء
البناء لا يعمل تلقائياً مع Push. تشغيله يدوي فقط من Actions كما تم الاتفاق.
