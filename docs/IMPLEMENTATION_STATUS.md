# حالة تنفيذ مَدار

## قاعدة الحالة
وجود شاشة أو Route لا يعني اكتمال الميزة. الميزة لا تُعد مكتملة إلا بعد تنفيذ منطقها وربط البيانات ومعالجة الأخطاء والاختبارات.

## تم تثبيته
- هوية مَدار ومعرف التطبيق `com.madar.app`.
- Flutter/Dart + Riverpod + GoRouter + Drift/SQLite.
- قاعدة بيانات محلية للمحتوى والمصادر والمفضلة والملاحظات والتقدم والتتبع.
- طبقة repositories مرتبطة بـ Drift.
- نظام مصدر/ترخيص/manifest والتحقق SHA-256.
- أساس حساب الصلاة والقبلة.
- أساس الصلاحيات مع طلب واضح.
- Design System وRoutes.
- GitHub Actions للبناء اليدوي فقط.

## قيد حالي مهم
- لا توجد بعد حزمة دينية رسمية مدخلة. لن نضع نصوصاً دينية مخترعة أو غير موثقة.
- حساب الصلاة يحتاج تحققاً مقابلاً لمراجع موثوقة قبل اعتماد الأرقام إنتاجياً.
- القبلة تحتاج حساس الجهاز + الموقع/الإحداثيات + معايرة فعلية.
- الإشعارات والأذان والصوت والتنزيلات تحتاج تكامل Android/iOS واختبارات جهاز.
- iOS يحتاج إعداد Apple signing وبيئة macOS.

## خطة الإغلاق
1. تثبيت build_runner وتوليد Drift والتحليل والاختبارات.
2. محرك بحث SQLite/FTS وربطه بالمحتوى.
3. المفضلة والملاحظات والتقدم والتتبع بشكل دائم.
4. قارئ القرآن الحقيقي وأنماط المصحف/القراءة/الدراسة.
5. الصلاة + الموقع اليدوي + الحساب والتحقق.
6. القبلة بالحساس والمعايرة.
7. الإشعارات والأذان والخلفية.
8. الصوت والتنزيلات.
9. حزم المحتوى الموثقة والمرخصة.
10. إكمال الأقسام الثانوية والربط الذكي.
11. اختبارات Android ثم iOS وإغلاق أخطاء البناء.

## سياسة الجودة
لا نستخدم بيانات تجريبية على أنها محتوى حقيقي، ولا نعلن اكتمال ميزة قبل اختبار مسار استخدامها.
