# MADAR | مَدار

تطبيق إسلامي حديث، موثوق، يعمل Offline-first، ويستهدف Android وiOS.

## الحالة
المشروع في مرحلة التأسيس والتنفيذ.

## مبادئ غير قابلة للتنازل
- صحة النصوص والمصادر قبل التصميم.
- لا يُكتب نص قرآني أو حديث من الذاكرة.
- كل مادة دينية تحمل مصدرها وترخيصها وبيانات التحقق.
- لا حذف أو استبدال لميزة معتمدة دون قرار موثق.
- البناء عبر GitHub Actions يدوي فقط، وليس مع كل Push.
- فصل المحتوى عن كود التطبيق قدر الإمكان.
- دعم RTL والعربية بجودة عالية.
- Offline-first للوظائف والمحتوى الأساسي.

راجع `docs/MADAR_PROJECT_SPECIFICATION.md` للتوثيق المرجعي للمشروع.
